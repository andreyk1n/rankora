# Rankora

WordPress-тема для SEO-агентства. Проєкт побудований на PHP, HTML, CSS і JavaScript із розділенням даних, шаблонів сторінок та повторно використовуваних компонентів.

## Структура проєкту

```text
rankora/
├── assets/
│   ├── css/
│   └── js/
├── data/
│   ├── global/
│   └── pages/
├── inc/
│   └── data-loader.php
├── template-parts/
│   ├── components/
│   └── partials/
├── templates/
│   └── page-service.php
├── 404.php
├── archive.php
├── footer.php
├── front-page.php
├── functions.php
├── header.php
├── index.php
├── page.php
├── single.php
├── README.md
└── style.css
```

## Основні директорії

- `assets/css/` — стилі сайту.
- `assets/js/` — JavaScript для інтерактивних елементів.
- `data/global/` — спільні дані сайту: шапка, підвал та інші глобальні елементи.
- `data/pages/` — дані та контент окремих сторінок.
- `inc/` — допоміжна PHP-логіка.
- `template-parts/components/` — повторно використовувані компоненти інтерфейсу.
- `template-parts/partials/` — частини шаблонів сторінок.
- `templates/` — спеціалізовані шаблони, зокрема сторінки послуг.

## Основні файли

- `functions.php` — налаштування теми та підключення CSS і JavaScript.
- `inc/data-loader.php` — завантаження даних із директорії `data/`.
- `front-page.php` — головна сторінка.
- `page.php` — стандартні сторінки WordPress.
- `single.php` — сторінка окремого запису.
- `archive.php` — архіви записів.
- `404.php` — сторінка помилки 404.
- `index.php` — резервний шаблон WordPress.
- `header.php` — шапка сайту.
- `footer.php` — підвал сайту.
- `style.css` — основна інформація про тему WordPress та її базові стилі.

## Принцип роботи

Проєкт використовує розділення контенту й представлення:

1. Дані зберігаються в `data/global/` та `data/pages/`.
2. `inc/data-loader.php` відповідає за завантаження даних.
3. Файли в `template-parts/` використовуються для побудови інтерфейсу з повторно використовуваних компонентів і частин шаблонів.
4. Файли в корені та `templates/` визначають структуру відповідних сторінок WordPress.

## Стилі та JavaScript

CSS-файли розміщуються в `assets/css/`, JavaScript — в `assets/js/`. Підключення ресурсів виконується через `functions.php`.

Для уникнення проблем із кешуванням під час розробки може використовуватися `filemtime()` як версія файлу.

## Розробка

1. Розмістити тему в `wp-content/themes/rankora/`.
2. Активувати її в адміністративній панелі WordPress.
3. Перевірити завантаження глобальних даних і даних сторінок.
4. Переконатися, що шаблони підключають потрібні компоненти.
5. Перевірити адаптивність, форми, навігацію та роботу JavaScript.
